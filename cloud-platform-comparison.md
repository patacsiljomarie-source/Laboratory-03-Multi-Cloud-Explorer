# Cloud Platform Comparison

## Comparison Table

| **Category** | **AWS** | **Microsoft Azure** | **Google Cloud Platform** |
|---|---|---|---|
| Launch Year | 2006 | 2010 | 2008 (major expansion ~2011–2013) |
| Compute Service | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage Service | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking Service | Amazon VPC | Azure Virtual Network (VNet) | Virtual Private Cloud (VPC) |
| Identity Service | AWS IAM | Azure Active Directory (Microsoft Entra ID) | Cloud IAM |
| Primary Strength | Widest range of services and market maturity | Deep integration with Microsoft products and hybrid cloud | AI/Machine Learning, data analytics, and Kubernetes |
| Ideal Organizations | Startups and enterprises needing the broadest service selection | Organizations already using Windows Server, Active Directory, or Microsoft 365 | AI research companies and data-driven businesses |

## Reflection Questions

**1. Which cloud provider offers the broadest range of services?**
AWS offers the broadest range of services, with over 200 fully-featured offerings covering nearly every area of cloud computing. Its long history since 2006 has allowed it to continuously expand into new service categories ahead of its competitors.

**2. Which provider best integrates with Microsoft technologies?**
Microsoft Azure best integrates with Microsoft technologies since it is built by Microsoft itself. It works seamlessly with Windows Server, Active Directory, Microsoft 365, and Dynamics 365, making it the natural choice for organizations already using these tools.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud Platform is the strongest in AI and Kubernetes. Google created Kubernetes and open-sourced it, giving GCP the most mature managed Kubernetes service (GKE). GCP is also known for powerful AI/ML tools like Vertex AI and BigQuery for data analytics.
