#Brief Overview
Microsoft Azure is Microsoft's cloud computing platform, launched in 2010. It's known for its strong integration with Microsoft products like Windows Server, Active Directory, and Microsoft 365 making it a popular choice for companies already using Microsoft software.

#Global Infrastructure
Azure operates across more regions than any other cloud provider — over 70 worldwide. It uses Regions (geographic areas with data centers), Availability Zones (separate facilities within a region for backup/redundancy), and Geographies (data residency boundaries like "Europe" or "United States" for compliance purposes).


#Cloud Management Console
This is the Azure Portal a web-based dashboard where you can create and manage resources visually, without needing to write code.

#Four (4) Core Services
* Virtual Machines – for computing power
* Blob Storage – for storing files/data
* Active Directory (Entra ID) – for identity and access management
* Azure SQL Database – for managed databases

#Three (3) Advantages
* Seamless integration with Microsoft products (Windows, Office, Active Directory)
* Strong hybrid cloud support (mixing on-premises servers with the cloud)
* Widest global region coverage, useful for data residency requirements

#Typical Enterprise Use Cases
Used by universities and companies already using Microsoft tools, by regulated industries (banking, healthcare) needing compliance features, and by organizations wanting a hybrid setup (part on-premises, part cloud).
